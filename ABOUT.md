# LeadFlow AI — Lead Management Dashboard

A dashboard built for AI voice agent businesses to manage 
inbound leads captured by AI phone systems.

## Live Demo
[View Live App](https://bolt.new/p/67713457)

## Features
- Track leads captured by AI voice agents
- Status management (New, Pending, Called Back, Converted)
- Conversion rate analytics
- Filter and search by business type
- Lead breakdown chart by industry

## Built With
- React
- Recharts
- Bolt.new
